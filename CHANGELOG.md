# Changelog

## 2.1.0: Cloud saves and backups
- **Save codes:** copy a short code on one device and enter it on another to bring your progress along. No account needed.
- **Save files:** export your progress as a backup file and import it on any device. On Android the file goes to your Downloads folder.
- **Cloud sync:** create an account with your email and a password and your progress syncs automatically between iPhone, Android, Windows and Mac. Plays offline as usual and syncs when you're back online.
- Find all of this in **Options → Cloud Save & Backups**. Loading a code or file only ever adds progress, so you can't lose levels by loading an older save.

## 2.0.0: Zombies in the Garden

Plant a garden and hold off waves of cartoon zombies before they reach the greenhouse.

### What's new in 2.0
- **Zombies!** 12 kinds of chunky cartoon garden zombies, each with something growing on its head: Farmhand, Lid, Jogger, Barrel, Acrobat, Brute, Scarecrow, Pumpkin-head, Gardener (heals its friends), Mailman (drops bonus dew), Parka (can't be slowed) and Skater (fast until hit).
- **5 worlds, 50 levels:** Backyard, Autumn Orchard (tap falling apples for 50 dew), Moonlit Garden (very little dew), Frosty Garden (icy lanes) and Sunny Beach (lots of dew that dries up fast). Some levels have rocks, logs, snowmen or sandcastles blocking squares.
- **4 new plants:** Thorn Rose (pierces the whole row), Ivy Snare (holds a zombie), Breeze Bloom (pushes zombies back) and Chestnut Lobber (lobs over shields). That makes 14 plants in all.
- **Seed picker:** once you own more than 10 plants, choose which ones to bring and see which zombies are coming.
- **New music** for each world, and zombie groans.
- Updated tutorial, How to Play book, Field Guide, Watch Demo mode and app icon.

### Downloads

| Platform | File | How to install |
|---|---|---|
| **iPhone / iPad** | No download needed | Open **https://sadirhossain0.github.io/sprot-seige/** in Safari, tap **Share → Add to Home Screen**, and open it once while online. It then works offline, fullscreen. |
| **Android** (5.0+) | `SproutSiege-2.0-Android.apk` | Open it on your phone and allow "Install unknown apps". If Play Protect warns, tap **More details → Install anyway**. Installs over older versions and keeps your progress. |
| **Windows** 10/11 | `SproutSiege-2.0-Windows.zip` | Extract, open the `Sprout Siege` folder, run **Sprout Siege.exe**. If SmartScreen appears: **More info → Run anyway**. |
| **Mac** (M1–M4) | `SproutSiege-2.0-Mac-AppleSilicon.zip` | Unzip, drag **Sprout Siege** into Applications, open it. The first time: **System Settings → Privacy & Security → Open Anyway**. |
| **Mac** (Intel) | `SproutSiege-2.0-Mac-Intel.zip` | Same as above. |
| **Any browser** | `SproutSiege-2.0-Web.zip` | The web app files, for hosting anywhere. Or just play at the link above. |

The security warnings appear because the apps aren't signed with paid Google, Microsoft or Apple developer certificates.
